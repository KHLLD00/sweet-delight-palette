# Sweet Delight Palette

Replace the visual pallete to Hot pink / magenta (primary brand color) — used for the whisk swirl outline, "EASE CAKES" text, and the "Luxury in Every Taste" ribbon. Roughly #EC1E8C / #F0409B

Dark brown / chocolate — used for "Cakes and Pastries" script text and the chocolate drip detail on the whisk. Roughly #3B1F1A / #4A2418

White / cream — the circular background and negative space, roughly #FFFFFF to #FDF6F0
